Work Board

GitLab

Leave the token empty to turn GitLab off. Make one in GitLab: User settings → Access tokens. Scope read_api is enough to see the lists. Pick api if you also want the "Done" button on mentions to work.

Jira

No token needed. The extension uses your Jira login in this browser. If you are not logged in, the popup shows a "Log in" button.

Gmail

No token needed. The extension uses your Google login in this browser. The number is the one in the Gmail address bar: mail.google.com/mail/u/0/. Use 1 if your work account is the second account you signed in with.

The Chat tab lists the emails Google Chat sends about mentions and direct messages you have not read. Turn them on in Google Chat: Settings → Email notifications. Google sends them only after a delay, so they show missed messages, not new ones.

Claude summaries

Leave empty to turn summaries off. Make a key at console.anthropic.com (you can log in there with Google). A Google login alone cannot be used here: the Claude API only accepts API keys. Each click on "Summarize" sends that one item to Claude and is billed to the key.
